# Bluestem Software website

Static site (no build step). Files: index.html, styles.css, favicon.svg.

## Before publishing, edit index.html
- Email: rhett@bluestemsoftware.com (swap in whatever domain you buy)
- Support & legal links currently point to the existing GitHub Pages pages; repoint them after the LLC name is added (checklist step 16)

## Deploy (checklist step 9)
1. Create a GitHub repo, push this folder's contents to the root, enable Pages (Settings > Pages > main branch).
2. After buying the domain, add a file named CNAME containing just the domain (e.g. bluestemsoftware.com), and set the DNS records from GitHub's custom domain guide.
